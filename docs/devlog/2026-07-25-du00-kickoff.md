**Goal:** with both D5 spikes merged, start DU-00 (the walking skeleton). Scope the unit against the authoritative docs, clear the blockers that gate execution, and land the first executable increment (toolchain + package skeleton) green-on-stubs.

## What happened

**Scoped DU-00.** Fanned out three readers over `test-strategy.md` / `tech-design.md` / `agent-ops.md` and reconciled against the delivery-plan + the 28-step ramp-up checklist. Net: DU-00 breaks into **8 PR-sized units** — a (toolchain) → b (constitution) → c (data-spine docs) → d (skeleton+seam) → e (evals+golden) → f (web) → g (CI) → h (Spec 001) — with three human checkpoints (A constitution, B settings, C first green CI). **Surfaced + resolved two hard blockers (Ben decided):**
1. **Branch protection is unavailable** — the repo is private on the GitHub free tier, so *both* the classic protection API and modern rulesets return `403 (Upgrade to Pro / make public)`. → **Deferred enforcement** (ADR-0005 already allows this): keep branches+PRs by convention; add required-checks when the repo goes public/Pro.
2. **The agent couldn't author CI** — shared `settings.json` hard-denied `Edit(./.github/workflows/**)`, and `deny` wins across layers. → **ADR-0006**: narrow the guardrail **deny → ask** (allowed but human-gated locally; fails closed in unattended cloud). `.env*`/`secrets` denies untouched.

**Landed unit a (toolchain + skeleton), green.** uv/Python 3.12 project; pinned geo stack resolved to the right majors (shapely 2.1.2, h3 4.5.0, osmnx 2.1.1, geopandas 1.1.4); empty importable packages `commons/planner/compiler/api` + `evals/tests` + a `web/` marker; skeleton smoke test. `uv run pytest/ruff/mypy` all green. LLM + eval deps deliberately deferred to their units (seam=d, evals=e), pinned there against current docs rather than guessed now.

## Decisions

- **ADR-0006** (accepted, Ben): narrow the CI workflow-edit deny to `ask`. Merged (PR #6).
- **Branch-protection enforcement deferred** under ADR-0005 (no new ADR) until the repo is public/Pro.
- **Cloud-vs-local guidance** established: local+fresh-session for any unit with a checkpoint, an `ask`-gated action, credentials/browser to verify, or first-runs to watch; cloud only from **M1/DU-01+** once CI gates PRs and Spec 001 exists. All remaining DU-00 units (b–h) are local by that rule.
- **Session hygiene**: one branch/PR per unit (ADR-0005); fresh session per unit from here.
